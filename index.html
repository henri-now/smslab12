SpO₂ calibration & processing

SpO₂ (%) = intercept + slope × R. Enter coefficients fitted for your sensor and this processing pipeline. No default coefficients are assumed. Values outside 0–100% are rejected. Calibration is kept only while this page is open.

After at least 8 seconds, samples are resampled to a uniform time grid. Separate second-order Butterworth high-pass (0.5 Hz) and low-pass (5 Hz) filters run forward and backward; one second at each edge is excluded. AC is the filtered standard deviation; DC is the absolute mean of the unfiltered channel over the same interior window. Heart rate uses the median interval between infrared peaks, with checks for interval regularity and red/infrared agreement. These checks cannot exclude all motion artifacts.

This filter differs from the Python viewer’s bandpass design; check calibration again when changing processing. Filter coefficients follow the W3C Audio EQ Cookbook.

How to connect
  1. Connect the XIAO using a USB data cable and flash the existing acquisition firmware.
  2. Close the Arduino serial monitor and Python viewer so the USB port is free.
  3. Open this page in desktop Chrome or Edge, click Connect USB, and choose the board. The connection uses 115200 baud.

Serve this folder with python3 -m http.server 8000 --bind 127.0.0.1, then open http://localhost:8000. Web Serial requires a supported browser and a secure context such as localhost or HTTPS. No data is uploaded.

Expected CSV: time_ms,off,red,ir,red_minus_off,ir_minus_off. Headers and firmware status messages are skipped. A board reset clears the plot.
